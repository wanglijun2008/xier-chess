📖 棋谱导入方式（四种方法导入棋谱听读）

  • 方法二：照片辅助录入点"录入"模式→点"选择/拍摄照片"上传棋谱照片→对照照片在棋盘上点击位置→点"完成录入并听读"

  • 方法四：文本粘贴在下方文本框输入坐标（格式见下方）→点"加载棋谱"

📖 棋谱导入格式（把书上的棋谱输入即可听读）

  • 国际坐标黑1 D4 / 白2 Q16 / 黑3 K10（字母A-T跳过I + 数字1-19，以黑方视角）
  • 中文坐标黑1 4-4（第4列第4行）白2 16-3（第16列第3行）
  • 围棋术语黑 星位 / 白 天元 / 黑 三三 / 白 小目
  • 标准SGF;B[pd] ;W[dp]（字母a-s对应1-19）
  • 字母简写B pd / W dp（每行一手）
  • 停手黑 停 / 白 Pass

💾 SGF格式说明（棋谱交换标准格式）

  • 什么是SGF：Standard Game Format，围棋界通用的棋谱文件格式，几乎所有围棋软件都支持
  • SGF格式示例：(;GM[1]FF[4]SZ[19];B[pd];W[dp];B[pq];W[qp])
  • 坐标编码：字母a-s对应第1-19行/列，a=1, b=2, ..., s=19。D4就是字母d(4)和字母d(4)组合
  • 如何获得SGF：
    • 📱 手机App（弈客/野狐/弈城）：对弈结束点"导出棋谱"或"保存棋谱"，选择SGF格式
    • 📷 拍照识谱：弈客围棋App支持拍照自动识别棋谱，可导出SGF
    • 💻 电脑软件（弈典/StoneBase）：打开棋谱后点"另存为"选择SGF格式
    • 🔄 在线转换：访问 https://www.lifein19x19.com 在线棋谱转换工具
  • 本软件支持：
    • 📁 直接导入.sgf文件（点"📁 导入SGF文件"按钮）
    • 💾 将当前棋局保存为SGF（点"💾 保存为SGF"按钮）
    • 📚 本地保存多个棋谱（点"📚 我的棋谱"管理已保存的棋谱）

国际坐标规则（以黑方视角）：列字母 A-T（跳过I）从左到右，行号 1-19 从下到上。
D4=左下星位，K10=天元，Q16=右上星位，A1=左下角，T19=右上角
中文坐标规则：列在前、行在后，范围1-19，从左上角开始。4-4=左上星位，10-10=天元
切换播报格式：按F键或点"坐标格式"按钮，可在中文（四之四）和国际（D4）间切换

🔧 安卓没有声音？按诊断面板提示排查：

  • ① 看顶部诊断面板的第1行红字提示，按提示操作
  • ② 手机媒体音量开到最大（不是铃声音量！安卓"媒体音量"和"铃声音量"是分开的）
  • ③ 点诊断里的"🔊测试语音"按钮，若没声音请按下方4-5步
  • ④ 若面板显示 "无中文语音"：打开手机设置→语言和输入法→文字转语音(TTS)输出，下载"普通话/中文"数据包，选"Google文字转语音引擎"或"讯飞/百度引擎"
  • ⑤ 若面板显示 "file://协议"（你当前就是！）：浏览器地址栏显示 file:// 开头会限制语音，改为用 HTTP服务器 打开（电脑开热点+Python http.server，或部署到静态网站），或用支持 file:// 协议的浏览器（如Via浏览器、X浏览器）
  • ⑥ 还不行：装 "Google 文字转语音引擎" 到手机，并在系统设置里把它设为默认TTS
